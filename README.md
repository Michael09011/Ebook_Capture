# 📚 Ebook Capture

AladinEbook(알라딘 전자책) 뷰어를 자동으로 캡처해서 PNG 이미지로 저장하는 macOS 전용 GUI 툴.

> **⚠️ 주의**: 개인 학습 및 연구 목적으로만 사용하세요. 저작권법을 준수해야 합니다.

---

## 주요 기능

- 🖥️ **GUI 인터페이스** — tkinter 기반, 별도 설치 없이 실행 가능
- 📸 **자동 화면 캡처** — 지정 좌표/크기 영역을 페이지 단위로 자동 캡처
- ⏸️ **일시정지 / 재개 / 중지** — 도중에 언제든 제어 가능
- 📊 **진행률 표시** — 프로그레스바 + 실행 로그 실시간 출력
- 🖱️ **화면 절전 방지** — 20페이지마다 마우스를 자동으로 흔들어 절전 차단
- 🔔 **완료 알림** — macOS 시스템 알림으로 작업 완료 통보

## 사용 방법

### 1단계 — 캡처 영역 좌표 확인

macOS **스크린샷** 또는 **개발자 도구**로 AladinEbook 뷰어의 책 본문 영역 좌표를 파악한다.

```
캡처 X    : 화면 좌측으로부터의 거리 (px)
캡처 Y    : 화면 상단으로부터의 거리 (px)
캡처 폭   : 캡처할 너비 (px)
캡처 높이 : 캡처할 높이 (px)
```

기본값은 `X=508, Y=67, W=672, H=933` (1920×1080 기준 예시).

### 2단계 — 툴 실행 및 설정 입력

| 설정 항목 | 설명 | 기본값 |
|-----------|------|--------|
| 앱 이름 | 캡처 대상 앱 이름 (macOS 앱 이름 정확히 입력) | `AladinEbook` |
| 저장 폴더 | PNG 저장 경로 | `~/Desktop/ebook/` |
| 총 페이지 | 캡처할 전체 페이지 수 | — |
| 캡처 X/Y/폭/높이 | 캡처 영역 좌표 | 위 기본값 참고 |
| 딜레이(초) | 페이지 넘김 후 대기 시간 | `1.0` |

### 3단계 — 시작

1. AladinEbook 앱에서 책을 열고 **첫 페이지**에 위치
2. 툴에서 **▶ 시작** 클릭
3. 약 2초 후 앱이 자동 활성화되며 캡처 시작

### 파일명 규칙

```
ebook_0001_2025-01-01_12-00-00.png
ebook_0002_2025-01-01_12-00-01.png
...
```

## PNG → PDF 변환

캡처한 PNG 파일을 PDF로 합치려면 별도 스크립트(`png2pdf.py`)를 사용한다.

```bash
python3 png2pdf.py
```

> 해당 스크립트는 저장 폴더의 PNG를 이름순으로 정렬해서 PDF 1파일로 병합한다.

## 주의사항

- **macOS 접근성 권한** 필요: `시스템 설정 > 개인 정보 보호 및 보안 > 접근성`에서 터미널(또는 Python)을 허용해야 함
- **화면 녹화 권한** 필요: `시스템 설정 > 개인 정보 보호 및 보안 > 화면 녹화`에서 허용
- 딜레이가 너무 짧으면 페이지 로딩 전에 캡처될 수 있음 → 네트워크 상태에 따라 `1.5~2.0`초 권장
- 캡처 도중 다른 창을 최상위로 올리면 영역이 가려짐
